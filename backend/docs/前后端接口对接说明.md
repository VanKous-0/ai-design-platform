# 前后端接口对接说明

## 1. 通用约定

### 1.1 返回结构

后端接口统一返回 `Result` 结构。前端应优先从 `data` 中读取业务数据。

典型结构：

```json
{
  "code": 200,
  "message": "success",
  "data": {}
}
```

具体字段以当前代码实现为准。

### 1.2 认证请求头

登录后访问需要 token 的接口，请携带：

```http
Authorization: Bearer <accessToken>
```

### 1.3 接口权限类型

| 类型 | 规则 | 示例 |
| --- | --- | --- |
| 公开接口 | 不需要 token | `POST /api/auth/login`、`GET /api/prompts` |
| 登录用户接口 | 需要有效 token | `/api/user/**`、`/api/workflow-instances/**` |
| 管理员接口 | 需要 `ADMIN` 权限 | `/api/admin/**` |

特别说明：

- `/api/auth/login` 公开。
- 部分 `/api/**` 展示接口公开。
- `/api/user/**` 需要登录。
- `/api/workflow-instances/**` 需要登录。
- `/api/ratings/tools`、`/api/ratings/workflows` 提交评分需要登录。
- `/api/admin/**` 需要 `ADMIN`。

## 5. 工作流实例

| 接口 | 方法 | Token | 请求体或参数 | 典型返回字段 | 前端使用场景 |
| --- | --- | --- | --- | --- | --- |
| `/api/workflow-instances` | `POST` | 是 | `templateId`、可选名称 | `instanceId`、模板信息、当前节点 | 用户启动工作流 |
| `/api/workflow-instances/my` | `GET` | 是 | 无 | 当前用户实例列表 | 我的工作流 |
| `/api/workflow-instances/{id}` | `GET` | 是 | `id` | 实例详情、节点记录 | 查看执行详情 |
| `/api/workflow-instances/{id}/progress` | `GET` | 是 | `id` | 总节点数、已完成数、进度 | 进度条展示 |
| `/api/workflow-instances/{id}/next-step` | `GET` | 是 | `id` | `nextNodeId`、`nextNodeName`、`nextTip`、`whetherFinished` | 下一步提示 |
| `/api/workflow-instances/{id}/steps/{nodeId}/complete` | `POST` | 是 | `inputContent`、`outputContent`、`durationSeconds` | 下一步信息 | 完成当前节点 |

完成节点请求示例：

```json
{
  "inputContent": "校园景观概念设计需求",
  "outputContent": "外部 AI 工具返回的方案结果",
  "durationSeconds": 120
}
```

请求示例：

```json
{
  "anonymousId": "visitor-001",
```

## 17. 公开案例展示

| 接口 | 方法 | Token | 请求参数 | 典型返回字段 | 前端使用场景 |
| --- | --- | --- | --- | --- | --- |
| `/api/cases` | `GET` | 否 | 分页或筛选参数 | 已审核案例列表 | 案例列表页 |
| `/api/cases/{id}` | `GET` | 否 | `id` | 已审核案例详情 | 案例详情页 |
| `/api/cases/{id}/assets` | `GET` | 否 | `id` | 资源 URL 列表 | 案例图片/文件展示 |
| `/api/cases/recommend` | `GET` | 否 | 可选条件 | 推荐案例 | 首页或推荐区 |

公开案例接口只返回：

```text
status = 1
is_deleted = 0
audit_status = APPROVED
```

`PENDING` 和 `REJECTED` 案例不会在公开接口中返回。
