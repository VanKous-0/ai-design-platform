# 工作流迭代结果接口说明

## 目标

当前后端不直接调用 AI API。用户在外部 AI 工具中生成结果后，可以把每轮提示词、输出、成果地址和质量评价记录到工作流节点中，用于结果对比和后续优化。

## 接口

| 接口 | 方法 | 说明 |
| --- | --- | --- |
| `/api/workflow-instances/{id}/steps/{nodeId}/iterations` | `POST` | 新增一轮外部 AI 结果 |
| `/api/workflow-instances/{id}/steps/{nodeId}/iterations` | `GET` | 按轮次查询节点结果 |
| `/api/workflow-instances/{id}/steps/{nodeId}/iterations/{iterationId}/select` | `PUT` | 选定该节点最终结果 |
| `/api/admin/exports/workflow-iterations.csv` | `GET` | 管理员导出实验数据 |

所有工作流迭代接口都要求登录，并校验工作流实例属于当前用户、节点属于该工作流模板。

## 新增一轮结果

```json
{
  "toolId": 1,
  "promptContent": "本轮实际使用的提示词",
  "outputContent": "外部 AI 返回结果或结果摘要",
  "resultUrl": "https://example.com/result.png",
  "effectScore": 8,
  "accuracyScore": 9,
  "controllabilityScore": 7,
  "usabilityScore": 8,
  "improvementNote": "下一轮加强场地边界和功能分区约束",
  "selected": false
}
```

四项评分范围均为 1 至 10，未填写的维度不参与平均分。`iterationNo` 由后端在同一实例、同一节点内自动递增。

## 选定最终结果

同一实例、同一节点最多只有一轮结果为 `selected = true`。调用选定接口时，后端会取消该节点之前选中的结果，再选中指定迭代。

## 验收重点

- 可以连续记录同一节点的多轮生成结果。
- 返回结果包含自动计算的 `averageScore`。
- 禁止操作其他用户的工作流迭代。
- 禁止向不属于该模板的节点写入迭代结果。
- CSV 可以按实验批次、实验组和日期筛选。
