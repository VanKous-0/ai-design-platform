# 后端模块结构说明

## 1. 模块总览

当前后端按 `common` 公共能力和 `modules` 业务模块组织。业务模块基本遵循：

```text
controller
service
service.impl
mapper
entity
dto
vo
```

`Entity` 只用于数据库映射，不直接返回给前端。接口响应应使用 `VO`，请求参数使用 `DTO` 或 `Request` 对象。

## 2. 公共模块

| Package | 模块职责 | 核心类 | 关联关系 |
| --- | --- | --- | --- |
| `com.project.common.result` | 统一接口返回结构 | `Result` | 所有 Controller 使用 |
| `com.project.common.exception` | 全局异常处理和业务异常 | `GlobalExceptionHandler`、业务异常类 | 所有 Service 可抛业务异常 |
| `com.project.common.config` | 安全配置、JWT 过滤器、OpenAPI 配置 | `SecurityConfig`、`JwtAuthenticationFilter`、`OpenApiConfig` | 影响所有接口鉴权和文档 |
| `com.project.common.util` | 公共工具 | JWT、认证相关工具类 | 用户 ID 获取、token 解析等 |

## 3. 业务模块说明

| Package | 模块职责 | 核心 Controller | 核心 Service | 核心表 | 主要接口 | 和其他模块的关系 |
| --- | --- | --- | --- | --- | --- | --- |
| `modules.auth` | 登录认证、JWT 签发 | `AuthController` | 认证 Service | `sys_user` | `POST /api/auth/login` | 登录成功后为用户侧和后台接口提供 token |
| `modules.user` | 用户基础信息 | `UserController` | 用户 Service | `sys_user` | `GET /api/user/me` | 被个人中心、评分、工作流实例、案例提交关联 |
| `modules.workflow` | 传统工作流阶段和步骤展示 | `WorkflowStageController`、后台工作流 Controller | 工作流展示 Service | `workflow_stage`、`workflow_step` | `GET /api/stages`、`GET /api/stages/{id}/steps` | 被新工作流模板节点可选关联，不被替换 |
| `modules.workflow.runtime` | 多套工作流模板和用户执行记录 | 工作流模板 Controller、工作流实例 Controller、后台模板节点 Controller | 工作流模板 Service、工作流实例 Service | `workflow_template`、`workflow_template_node`、`workflow_instance`、`workflow_step_record` | `GET /api/workflow-templates`、`POST /api/workflow-instances`、`POST /api/workflow-instances/{id}/steps/{nodeId}/complete` | 关联提示词节点匹配、用户评分、统计分析 |
| `modules.prompt` | 提示词库、节点匹配、参数化渲染 | `PromptController`、后台提示词 Controller | 提示词 Service | `prompt_template`、`prompt_tool_rel`、`workflow_node_prompt_rel`、`prompt_parameter` | `GET /api/prompts`、`GET /api/prompts/by-node`、`POST /api/prompts/{id}/render` | 关联 AI 工具、工作流节点、行为日志 |
| `modules.tool` | AI 工具库和专业测评 | `AiToolController`、后台工具 Controller | 工具 Service、测评 Service | `ai_tool`、`ai_tool_stage_rel`、`evaluation_dimension`、`ai_tool_evaluation` | `GET /api/tools`、`GET /api/tools/{id}/evaluations` | 区分管理员专业测评和普通用户评分 |
| `modules.caseproject` | 案例展示、用户案例提交、管理员审核 | `CaseProjectController`、`UserCaseController`、`AdminCaseProjectController` | 案例 Service | `case_project`、`case_asset` | `GET /api/cases`、`POST /api/user/cases`、`POST /api/admin/cases/{id}/approve` | 关联用户、工具、阶段；公开接口只展示 `APPROVED` 案例 |
| `modules.review` | 复盘内容展示 | `ReviewController`、后台复盘 Controller | 复盘 Service | `review_record`、`review_asset` | `GET /api/reviews`、`GET /api/reviews/{id}` | 可被行为日志统计浏览行为 |
| `modules.site` | 首页内容和获奖记录 | `SiteController`、后台首页 Controller | 首页内容 Service | `site_content`、`award_record` | `GET /api/site/home`、`GET /api/awards` | 为前台首页提供展示数据 |
| `modules.profile` | 个人中心、设计偏好、最近参数 | `UserProfileController`、偏好和参数 Controller | Profile Service、Preference Service、RecentParameter Service | `user_profile`、`user_design_preference`、`user_recent_parameter` | `GET /api/user/profile`、`PUT /api/user/preferences`、`POST /api/user/recent-parameters` | 为提示词渲染和前端自动回填提供用户数据 |
| `modules.rating` | 普通用户评分体系 | `RatingController` | Rating Service | `user_tool_rating`、`user_workflow_rating` | `POST /api/ratings/tools`、`GET /api/ratings/tools/summary` | 和 `ai_tool_evaluation` 分离；被统计模块复用 |
| `modules.statistics` | 行为日志、问卷反馈和后台统计 | `UsageEventController`、`SurveyFeedbackController`、`AdminStatisticsController` | UsageEvent Service、SurveyFeedback Service、Statistics Service | `usage_event`、`survey_feedback` | `POST /api/usage-events`、`GET /api/admin/statistics/usage-summary` | 聚合提示词、工作流、评分、问卷和行为数据 |

## 4. 权限边界

| 接口类型 | 路径示例 | 权限 |
| --- | --- | --- |
| 登录接口 | `POST /api/auth/login` | 公开 |
| 前台展示接口 | `GET /api/tools`、`GET /api/prompts`、`GET /api/cases` | 通常公开 |
| 普通用户接口 | `GET /api/user/profile`、`POST /api/workflow-instances` | 需要登录 |
| 评分提交接口 | `POST /api/ratings/tools`、`POST /api/ratings/workflows` | 需要登录 |
| 评分汇总接口 | `GET /api/ratings/tools/summary` | 公开 |
| 行为和问卷提交 | `POST /api/usage-events`、`POST /api/survey-feedback` | 公开，带 token 时记录用户 |
| 后台管理接口 | `/api/admin/**` | 需要 `ADMIN` |

## 5. 模块关系重点

| 关系 | 说明 |
| --- | --- |
| `workflow_template_node` 和 `workflow_stage` / `workflow_step` | 新工作流节点可选关联旧阶段和步骤；旧表不被替换 |
| `workflow_node_prompt_rel` 和 `prompt_template` | 一个工作流节点可推荐多个提示词 |
| `prompt_parameter` 和 `prompt_template` | 定义提示词内容中的 `{paramKey}` 参数 |
| `user_tool_rating` 和 `ai_tool_evaluation` | 前者是普通用户反馈，后者是管理员维护的专业测评 |
| `usage_event` 和各业务表 | 通过 `targetType`、`targetId` 关联工具、提示词、案例、工作流等 |
| `case_asset` 和 `case_project` | 资源是否公开由所属案例的 `audit_status` 决定 |
