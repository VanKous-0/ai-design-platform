# 当前版本功能边界说明

## 1. 当前版本实际定位

当前版本定位为：

```text
AI 工具导航 + 工作流引导 + 提示词模板 + 参数化生成 + 使用记录 + 用户评价 + 数据统计 + 案例沉淀
```

平台当前重点是把建筑/景观设计中的 AI 辅助过程组织起来，形成可执行、可记录、可评价、可统计的流程闭环。

## 2. 当前版本已经实现什么

| 方向 | 当前能力 |
| --- | --- |
| 用户登录 | 支持登录、JWT、当前用户信息 |
| 工作流 | 支持模板、节点、执行实例、步骤记录、下一步提示 |
| 提示词 | 支持列表、搜索、推荐、节点匹配、参数化渲染 |
| AI 工具 | 支持工具库、适用阶段和管理员专业测评 |
| 用户数据 | 支持个人资料、设计偏好、最近参数 |
| 用户反馈 | 支持工具评分和工作流评分 |
| 行为记录 | 支持 `usage_event` 埋点 |
| 问卷反馈 | 支持轻量 `survey_feedback` |
| 后台统计 | 支持行为、提示词、工作流和评分统计 |
| 案例 | 支持公开案例、用户提交案例、管理员审核 |

## 3. 当前版本不做什么

### 3.1 不接入真实外部 AI API

当前版本不做：

- 不接入真实外部 AI API
- 不调用 OpenAI、DeepSeek、通义、豆包、Kimi、ChatGPT 等模型接口
- 不配置 API Key
- 不做模型调用 Service
- 不做 token 计费
- 不做流式输出

当前处理方式：

1. 平台提供提示词模板。
2. 用户填写参数。
3. 后端渲染完整提示词。
4. 用户复制提示词。
5. 用户到外部 AI 工具中完成生成。
6. 用户将结果粘贴回平台，用于工作流记录和案例沉淀。

### 3.2 不做真实文件上传

当前版本不做：

- 不做真实文件上传
- 不做 `MultipartFile` 文件保存
- 不做云存储
- 不做视频上传
- 不做视频转码
- 不做大文件处理

当前处理方式：

| 资源类型 | 当前保存方式 |
| --- | --- |
| 案例封面 | 保存 `coverUrl` 字符串 |
| 案例图片 | 保存 `assetUrl` 字符串 |
| 案例文件 | 保存 `assetUrl` 字符串 |
| 视频资源 | 当前若需要展示，只保存 URL；视频中心当前未实现 |

## 4. 为什么当前阶段不做这些能力

| 原因 | 说明 |
| --- | --- |
| 成本控制 | 真实 AI API 调用会产生 token 或调用费用，不适合在当前阶段默认开启 |
| 密钥安全 | API Key 配置和管理需要更严格的安全策略，当前阶段先不引入 |
| 部署稳定性 | 流式输出、文件上传、视频转码会显著增加部署复杂度 |
| 项目重点 | 大创当前阶段重点是流程组织、提示词辅助和数据闭环 |
| 验收可控 | URL 资源和外部 AI 工具配合使用，便于演示和验收 |
| 后续扩展 | 当前结构可以为统一 AI 调用层和对象存储预留接口 |

## 5. 当前版本和真实 AI 平台的区别

| 对比项 | 当前版本 | 真实 AI 调用平台 |
| --- | --- | --- |
| 模型调用 | 不调用 | 后端调用模型 API |
| API Key | 不配置 | 需要安全存储和权限控制 |
| 生成结果 | 用户从外部工具复制回平台 | 平台直接返回模型输出 |
| token 计费 | 不涉及 | 需要计费、限流、日志 |
| 流式输出 | 不支持 | 可能需要 SSE 或 WebSocket |
| 文件处理 | 只保存 URL | 需要上传、存储、鉴权、清理 |

## 6. 后续可扩展方向

当前版本后续可以平滑扩展：

| 扩展方向 | 说明 |
| --- | --- |
| 统一 AI 调用层 | 封装模型供应商、API Key、调用日志、错误处理 |
| 模型调用记录 | 记录 prompt、response、耗时、token 消耗 |
| 流式输出 | 使用 SSE 或 WebSocket 返回生成过程 |
| 文件上传 | 接入对象存储，保存文件元数据和访问 URL |
| 视频中心 | 增加视频资料表、观看记录和评分 |
| 统计可视化 | 在后台将统计接口对接图表 |

## 7. 文档口径建议

对外介绍当前版本时，建议使用以下表述：

> 当前平台不直接调用外部 AI 模型，而是提供 AI 辅助设计流程组织、工具导航、提示词模板、参数化提示词生成、过程记录、用户评价和统计分析能力。用户可将平台生成的提示词复制到外部 AI 工具中完成生成，再将结果回填平台形成流程记录和案例沉淀。

不建议表述为：

- “平台已经接入 ChatGPT”
- “平台可以直接生成 AI 图片”
- “平台支持视频上传和转码”
- “平台已经实现云存储”

以上能力当前未实现，后续可扩展。
