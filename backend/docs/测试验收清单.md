# 测试验收清单

## 1. 基础说明

本清单用于后端阶段验收。建议先准备：

- 管理员账号：以初始化脚本为准，例如 `admin`
- 普通用户账号：如已执行初始化脚本，可使用 `testuser / test123`
- 请求头：`Authorization: Bearer <accessToken>`
- 数据库脚本：按 `docs/数据库脚本执行顺序.md` 执行

## 2. 第一阶段验收：工作流执行闭环和提示词增强

- [ ] `GET /api/workflow-templates` 可以查询工作流模板。
- [ ] `GET /api/workflow-templates/{id}` 可以查询模板详情和节点。
- [ ] 登录用户调用 `POST /api/workflow-instances` 可以创建工作流实例。
- [ ] 登录用户调用 `GET /api/workflow-instances/my` 可以查询自己的实例。
- [ ] 登录用户调用 `GET /api/workflow-instances/{id}/next-step` 可以查询下一步。
- [ ] 登录用户调用 `POST /api/workflow-instances/{id}/steps/{nodeId}/complete` 可以完成步骤。
- [ ] 完成步骤后返回 `nextNodeId`、`nextNodeName`、`nextTip`、`whetherFinished`。
- [ ] 登录用户调用 `GET /api/workflow-instances/{id}/progress` 可以查询进度。
- [ ] 普通用户不能查看或操作别人的 `workflow_instance`。
- [ ] `GET /api/prompts/by-node?nodeId=1` 可以查询节点匹配提示词。
- [ ] `GET /api/prompts/{id}/parameters` 可以查询提示词参数。
- [ ] `POST /api/prompts/{id}/render` 可以渲染参数化提示词。
- [ ] 必填参数缺失时，`render` 接口返回业务异常。
- [ ] 原有 `GET /api/prompts/{id}` 不受影响。
- [ ] 原有 `POST /api/prompts/{id}/copy` 不受影响。

## 3. 第二阶段验收：用户闭环

- [ ] `testuser` 可以正常登录。
- [ ] 登录用户调用 `GET /api/user/profile` 可以查询个人资料。
- [ ] 登录用户调用 `PUT /api/user/profile` 可以修改个人资料。
- [ ] 登录用户调用 `GET /api/user/preferences` 可以查询设计偏好。
- [ ] 登录用户调用 `PUT /api/user/preferences` 可以修改设计偏好。
- [ ] 登录用户调用 `GET /api/user/recent-parameters` 可以查询最近参数。
- [ ] 登录用户调用 `POST /api/user/recent-parameters` 可以新增最近参数。
- [ ] 最近参数重复提交时，`useCount` 增加。
- [ ] 登录用户调用 `DELETE /api/user/recent-parameters/{id}` 可以删除自己的参数。
- [ ] 普通用户不能删除别人的最近参数。
- [ ] 登录用户调用 `POST /api/ratings/tools` 可以提交工具评分。
- [ ] 同一用户重复提交同一工具评分时更新原记录。
- [ ] `GET /api/ratings/tools/summary?toolId=1` 可以公开查询工具评分汇总。
- [ ] 登录用户调用 `POST /api/ratings/workflows` 可以提交工作流评分。
- [ ] 提交工作流评分时，`instanceId` 必须属于当前用户。
- [ ] `templateId` 必须和 `instanceId` 对应实例一致。
- [ ] `GET /api/ratings/workflows/summary?templateId=1` 可以公开查询工作流评分汇总。
- [ ] 未登录用户不能访问 `/api/user/**`。
- [ ] 未登录用户不能提交评分。
- [ ] 用户评分不写入 `ai_tool_evaluation`。

## 4. 第三阶段验收：行为日志与统计分析

- [ ] 匿名用户可以调用 `POST /api/usage-events` 提交行为日志。
- [ ] 匿名 `usage_event` 可以保存 `anonymousId`。
- [ ] 带 token 调用 `POST /api/usage-events` 时能记录 `userId`。
- [ ] `inputSummary` 不保存过长内容。
- [ ] `extraJson` 只按字符串保存。
- [ ] 匿名用户可以调用 `POST /api/survey-feedback` 提交问卷反馈。
- [ ] 带 token 提交 `survey_feedback` 时能记录 `userId`。
- [ ] 管理员可以调用 `GET /api/admin/survey-feedback` 查看反馈。
- [ ] 管理员可以调用 `GET /api/admin/statistics/usage-summary` 查看行为总览。
- [ ] 管理员可以调用 `GET /api/admin/statistics/event-type-summary` 查看事件类型统计。
- [ ] 管理员可以调用 `GET /api/admin/statistics/target-type-summary` 查看目标类型统计。
- [ ] 管理员可以调用 `GET /api/admin/statistics/prompt-summary` 查看提示词统计。
- [ ] 管理员可以调用 `GET /api/admin/statistics/workflow-summary` 查看工作流统计。
- [ ] 管理员可以调用 `GET /api/admin/statistics/tool-rating-summary` 查看工具评分统计。
- [ ] 管理员可以调用 `GET /api/admin/statistics/workflow-rating-summary` 查看工作流评分统计。
- [ ] 无数据时统计接口返回 `0` 或空数组，不抛异常。
- [ ] `startDate > endDate` 时返回业务异常。
- [ ] 普通 `USER` 不能访问 `/api/admin/statistics/**`。
- [ ] 未登录用户不能访问 `/api/admin/statistics/**`。

## 5. 第四阶段验收：用户案例提交与管理员审核

- [ ] 登录用户可以调用 `POST /api/user/cases` 提交案例。
- [ ] 用户提交案例默认 `auditStatus = PENDING`。
- [ ] `PENDING` 案例在 `GET /api/cases` 中查不到。
- [ ] `PENDING` 案例在 `GET /api/cases/{id}` 中查不到。
- [ ] 管理员调用 `GET /api/admin/cases/pending` 能看到待审核案例。
- [ ] 管理员调用 `GET /api/admin/cases/audit-list` 能按审核状态查询案例。
- [ ] 管理员调用 `POST /api/admin/cases/{id}/approve` 可以审核通过案例。
- [ ] 审核通过后，案例变为 `APPROVED`。
- [ ] `APPROVED` 案例可以在公开接口中查到。
- [ ] 管理员调用 `POST /api/admin/cases/{id}/reject` 可以驳回案例。
- [ ] 审核驳回后，案例变为 `REJECTED`。
- [ ] `REJECTED` 案例在公开接口中查不到。
- [ ] 用户可以调用 `GET /api/user/cases/my` 查看自己的案例。
- [ ] 用户可以调用 `GET /api/user/cases/{id}` 查看自己的案例详情。
- [ ] 用户可以修改自己的 `PENDING` 案例。
- [ ] 用户可以修改自己的 `REJECTED` 案例，修改后重新变为 `PENDING`。
- [ ] 用户修改自己的 `APPROVED` 案例后重新变为 `PENDING`。
- [ ] 用户不能修改别人的案例。
- [ ] 用户可以调用 `POST /api/user/cases/{id}/assets` 给自己的案例新增资源 URL。
- [ ] 用户可以调用 `DELETE /api/user/case-assets/{id}` 删除自己案例下的资源。
- [ ] 用户不能删除别人案例下的资源。
- [ ] `GET /api/cases/{id}/assets` 查询资源前会确认案例为 `APPROVED`。
- [ ] `case_asset` 不单独审核，资源公开依赖所属 `case_project.audit_status`。
- [ ] 本阶段不做真实文件上传。
- [ ] 本阶段不使用 `MultipartFile`。
- [ ] 本阶段不做视频上传。
- [ ] 本阶段不接入 AI API。
